Experience, Products and Achievements remain empty. At the user's request, the original navigation and page visibility were restored from the pre-cleanup backup; empty sections remain accessible. Skills have null proficiency scores; their descriptions identify supporting projects. Timeline dates are GitHub repository creation dates, explicitly labelled as such, not employment or launch dates. Personal OS logs and targets remain user-entered.

The resume is an editorial project-based resume composed from the same verified identity and implementation summaries. Project covers are typography and technology title cards, not application screenshots. Payment integration code is described without claiming live merchant activation. Only the portfolio URL supplied by the profile is used as a live project link.

## Content and publishing

Curated payload: `Backend/content/github-portfolio.json`.
Import through the authenticated local CMS API: `npm run import:github-profile -- --apply` from Backend. A snapshot of the CMS content is saved under the Git-ignored `.local-backups` directory before writes. Imported skills and projects are matched by stable names/repository URLs to avoid duplicates on retry. Import is never called on server startup.
